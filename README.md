# NEON//PULSE

Мобильная ритм-игра в одном `index.html` — без библиотек и сборки. Музыка синтезируется на лету через Web Audio API: BPM растёт от 96 (synthwave) до 172 (drum & bass).

## Механики

| Режим | Что делать | Как считается |
|---|---|---|
| **TILT** | Наклоняй телефон (DeviceOrientation), держи шарик на цветной дуге | Проверка точно в бит, 4 раза за такт |
| **TRACE** | Веди пальцем за пульсом по неоновому узору | Доля времени, когда палец рядом с пульсом |
| **DROP** | Тапай по экрану или хлопни/крикни в микрофон | Окно ±60 мс — Perfect, ±140 мс — Good |

Перегрузка (Rhythm Overdrive) заполняется от точных попаданий и даёт ×2 к очкам.

## Запуск

Гироскоп и микрофон работают только по **HTTPS**. Самый простой путь — GitHub Pages: *Settings → Pages → Deploy from branch → main / root*.

Локально: `npx serve` и открыть через HTTPS-туннель (например, `cloudflared tunnel`). На десктопе управление — `←` `→`, пробел и мышь.

## Файлы

- `index.html` — вся игра
- `manifest.webmanifest` — установка как PWA
- `icon.svg`, `icon-maskable.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `icon-180.png` — иконки приложения

Микрофон ловит и музыку из динамика, поэтому играй в наушниках; во время DROP громкость музыки автоматически снижается.
